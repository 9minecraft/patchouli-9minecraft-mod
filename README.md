# Patchouli 9minecraft Mod - Read Mod Guides Without Leaving Minecraft

Patchouli 9minecraft Mod is an accessible, data-driven documentation library that lets you build beautiful in-game guidebooks entirely through data files - no coding required - so players can read tips, recipes, and lore in a clean, page-turning book right inside the game. Rather than adding blocks or items of its own, Patchouli provides the framework for creating illustrated guide books.

## What this build is

An unofficial rebuild of **Vazkii, williewillus**'s original work, kept running on current releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Loader: Fabric, NeoForge.

## Source
